# Генератор трубы для Gmsh — подробная инструкция

Программа создаёт `.geo`-файл с трёхмерной hex-сеткой трубы для программы **Gmsh**. Труба может состоять из любого числа прямых участков и поворотов. Все параметры вводятся в консоли на русском языке.

## 1. Что нужно для запуска

- **Python 3.10 или новее** — язык программирования, на котором написана программа
- **Gmsh** — программа для просмотра и построения сетки: [gmsh.info](https://gmsh.info)

Дополнительных библиотек устанавливать не нужно — всё используемое входит в стандартный Python.

---

## 2. Как запустить

Откройте терминал (командную строку) в папке с файлом `project.py` и введите:

### Обычный режим — ввод параметров вручную
```
python project.py
```
Программа задаст все вопросы по очереди. Вы отвечаете на каждый и нажимаете Enter.

### Демо-режим — готовый пример без вопросов
```
python project.py --demo
```
Сразу создаёт файл `pipe.geo` с демонстрационной трубой:
- Прямой участок длиной 10
- Поворот на 45° вокруг оси Y
- Прямой участок длиной 20

Удобно, чтобы посмотреть как выглядит результат, прежде чем вводить свои параметры.

## 3. Как работает ввод в консоли

### Квадратные скобки — значение по умолчанию

Каждый вопрос выглядит примерно так:
```
Диаметр трубы [2]:
```

Число в квадратных скобках `[2]` — это **значение по умолчанию**. Оно будет использовано автоматически, если вы просто нажмёте **Enter** без ввода чего-либо.

Если хотите другое значение — наберите его и нажмите Enter:
```
Диаметр трубы [2]: 5
```

### Откуда берутся значения по умолчанию

Не все дефолты одинаковы. Одни фиксированные, другие вычисляются из того, что вы ввели раньше:

| Вопрос | Откуда дефолт |
|---|---|
| Диаметр трубы | Фиксировано: `2` |
| Диагональ ромба | **80% от диаметра** — меняется если вы ввели другой диаметр |
| Радиус поворота | **10 × радиус трубы** — меняется от диаметра |
| Количество слоёв | **Длина участка / (0.5 × диаметр)** — чем длиннее участок, тем больше слоёв |

Это значит: если вы ввели диаметр `4` вместо `2`, то следующий дефолт для диагонали ромба уже будет `[3.2]`, а не `[1.6]`.

### Ввод чисел

- Дробная часть отделяется **точкой** или **запятой** — оба варианта работают: `1.5` и `1,5` одинаковы.
- Если введёте некорректное значение или выйдете за допустимый диапазон — программа попросит повторить.

### Вопросы да/н

Некоторые вопросы требуют ответа да или нет:
```
Задать шаг вдоль трубы через долю/количество диаметров (д/н) [д]:
```
Допустимые ответы: `д`, `да`, `y`, `yes` — или `н`, `нет`, `n`, `no`. Регистр не важен. Значение в скобках `[д]` — тоже по умолчанию, просто Enter = да.

## 4. Шаг 1 — Поперечное сечение трубы

Программа сначала спрашивает параметры поперечного сечения. Сечение — это круг с особой структурой сетки внутри: в центре находится ромб (квадрат, повёрнутый на 45°), а вокруг него — четыре «лепестка» до стенки круга.

```
Геометрия поперечного сечения и сетка
```

### Диаметр трубы `[2]`
Внешний диаметр трубы. Все остальные размеры масштабируются от него.

### Длина диагонали ромба внутри круга `[1.6]`
Ромб — это центральное ядро сетки. Его диагональ должна быть **меньше диаметра трубы**.
- Слишком маленький ромб → плохое соотношение сторон ячеек у стенки
- Слишком большой ромб → ячейки в «лепестках» становятся вырожденными
- Рекомендуется: ~70–85% от диаметра (дефолт 80%)

### Сколько квадратиков на одну сторону ромба-ядра `[8]`
Количество ячеек вдоль одной стороны центрального ромба. Влияет на густоту сетки в центре трубы.
- Меньше → грубее, быстрее считается
- Больше → точнее, медленнее

### Сколько прямоугольников от ромба до стенки круга `[12]`
Количество слоёв ячеек между ромбом и стенкой трубы. Здесь обычно нужна более мелкая сетка — особенно для задач с погранслоем.

### Сгущение к стенке круга `[1.2]`
Управляет тем, как распределены ячейки от ромба к стенке:
- `1` — равномерное распределение
- `> 1` — ячейки мельче у стенки (рекомендуется для вязкого течения)
- `< 1` — ячейки мельче у ромба (редко нужно)

## 5. Шаг 2 — Участки трубы

### Количество участков `[3]`
Труба состоит из последовательных участков. Введите их общее число. Минимум — 1.

Затем для каждого участка программа спрашивает его тип:
```
Тип участка: 1 = прямая, 2 = поворот [1]:
```

---

### Прямой участок (тип `1`)

#### Длина прямого участка
Длина отрезка трубы. Должна быть больше нуля.
- Дефолт для первого участка — `[10]`, для остальных — `[20]`

#### Направление прямого участка
Вектор, показывающий куда «смотрит» труба. Вводится как три числа через запятую.
- Дефолт — направление предыдущего участка (или `0,0,1` для первого)
- Длина вектора не важна — программа нормирует его автоматически

Подробнее о векторах — в [разделе 7](#7-как-задавать-векторы).

#### Количество слоёв вдоль участка

Сначала программа спросит:
```
Задать шаг вдоль трубы через долю/количество диаметров (д/н) [д]:
```

**Если ответить `д`** — программа спросит шаг в единицах диаметра:
```
Шаг вдоль трубы (0.1 = мелко, 5 = грубо) [0.5]:
```
Шаг `0.5` означает: одна ячейка на половину диаметра. При длине `10` и диаметре `2` это даст `10 / (0.5 × 2) = 10` слоёв.

**Если ответить `н`** — введите количество слоёв напрямую.

#### Сгущение вдоль участка `[1]`
- `1` — равномерно
- `> 1` — ячейки мельче к **концу** участка
- `< 1` — ячейки мельче к **началу** участка

---

### Поворот (тип `2`)

#### Радиус поворота по оси трубы
Радиус дуги, по которой изгибается ось трубы. **Должен быть больше радиуса трубы** — иначе программа увеличит его автоматически до минимально допустимого.
- Дефолт: `10 × радиус трубы`

#### Ось вращения поворота
Вектор, вокруг которого происходит поворот. Например, `0,1,0` — поворот в плоскости XZ.
- Если ось окажется не перпендикулярна трубе — программа спроецирует её автоматически

#### Направление от начала поворота к центру кривизны
Вектор, указывающий от текущего положения трубы к центру окружности поворота. Определяет, в какую сторону изгибается труба.
- Например, `1,0,0` — центр поворота находится в направлении оси X

#### Угол поворота в градусах
Угол дуги, на которую поворачивает труба. Допустимый диапазон: от `-180` до `180` (не включая `0`).
- Положительный угол — поворот в одну сторону, отрицательный — в другую
- Направление зависит от ориентации оси вращения по правилу правой руки

#### Количество слоёв вдоль поворота
Аналогично прямому участку. Расчётная длина — длина дуги: `угол_в_радианах × радиус_поворота`.

#### Сгущение вдоль поворота `[1]`
Аналогично прямому участку.

## 7. Как задавать векторы

Вектор — это три числа через запятую: `X,Y,Z`. Вместо запятой можно использовать точку с запятой.

Векторы используются для задания направления и осей. Длина вектора не важна — программа нормирует автоматически. То есть `0,0,1` и `0,0,5` дадут одинаковый результат.

### Стандартные направления

| Вектор | Направление |
|---|---|
| `1,0,0` | Вдоль оси X |
| `0,1,0` | Вдоль оси Y |
| `0,0,1` | Вдоль оси Z |
| `-1,0,0` | Против оси X |
| `1,1,0` | По диагонали в плоскости XY (45°) |

### Нулевой вектор

Вектор `0,0,0` недопустим — программа вернёт ошибку и попросит повторить ввод:
```
Ошибка: нужен ненулевой вектор вида 0,0,1
```

## 8. Что делать с готовым файлом

После завершения ввода программа выведет:
```
Готово: создан файл pipe.geo
```

### Открыть в Gmsh вручную

1. Запустите Gmsh
2. Откройте файл: **File → Open** → выберите `pipe.geo`
3. Вы увидите геометрию трубы (без сетки)
4. Постройте сетку: **Mesh → 3D**
5. Экспортируйте: **File → Export** → выберите нужный формат (например `.msh`)

### Построить сетку через командную строку
```
gmsh pipe.geo -3
```
Ключ `-3` означает построить объёмную (3D) сетку. Gmsh сохранит её в файл `pipe.msh`.

### Почему сетка не строится при открытии файла

Это сделано намеренно. Команда `Mesh 3;` в файле закомментирована, чтобы Gmsh не начинал долгое вычисление автоматически при открытии. Сетку нужно запустить вручную.

## 9. Автоисправления и предупреждения

### Предупреждение о большом числе ячеек

Если расчётное количество объёмных ячеек превысит **1 000 000**, программа выведет:
```
Внимание: расчётно получится больше 1 000 000 объёмных ячеек.
Gmsh может долго строить сетку или закрыться из-за памяти.
```
Это не ошибка — геометрия корректна. Но построение сетки может занять долгое время или потребовать много оперативной памяти. Чтобы уменьшить число ячеек, снизьте:
- Количество квадратиков на сторону ромба
- Количество прямоугольников от ромба до стенки
- Количество слоёв вдоль участков

### Автоисправление оси поворота

Если заданная ось вращения не перпендикулярна трубе, программа автоматически проецирует её в допустимое положение. В `.geo`-файл добавляется комментарий:
```
// АВТОИСПРАВЛЕНИЕ: Ось поворота не была перпендикулярна текущей трубе; она автоматически спроецирована в допустимое положение.
```

### Автоисправление радиуса поворота

Если радиус поворота меньше или равен радиусу трубы — это геометрически невозможно. Программа увеличит его до минимально допустимого значения и сообщит об этом:
```
// АВТОИСПРАВЛЕНИЕ: Радиус поворота был меньше/равен радиусу трубы; увеличен до безопасного минимума 1.001 вместо 1.
```
